# 星屑ライブラリ ― 消えた彗星と七日間の夏

全年齢向けブラウザ・ビジュアルノベル（1作品完結）。

閉館まで七日。海辺の町・星見町の図書館プラネタリウムを、30年ぶりに回帰する彗星「アストライア」の夜にもう一度開くため、大学生の天文サークルと図書館の仲間たち五人の夏を描く青春群像ミステリ。

## 遊び方
`index.html` をブラウザで開くだけで遊べます（サーバー不要）。GitHub Pages でも公開しています。

- クリック／タップで文章送り、選択肢で物語が分岐します
- クイックバー：Q.SAVE / SAVE / LOAD / AUTO / SKIP（既読のみ）/ LOG / CONFIG / HIDE / TITLE
- セーブは12枠×10ページ＋クイックセーブ、ブラウザに保存されます
- CONFIG で文字速度・文字サイズ・フォント・メッセージウィンドウの濃さ・BGM/SE音量などを変更できます（全て実際に反映されます）
- エンディング到達で EXTRA（分岐フローチャート／ギャラリー／エンディング一覧）が解放されます

## 収録内容
- 全956ノード・本文69,680字、共通ルート5章＋キャラルート4本
- エンディング全9種（TRUE×1 / GOOD×4 / NORMAL×4）
- 登場人物5人全員に立ち絵＋表情差分5種（通常／笑顔／悲しみ／驚き／真剣）＝25枚
- 背景8枚、キービジュアル1枚
- BGM 7曲（場面で切替）・SE 14種（全て自作シンセ生成）
